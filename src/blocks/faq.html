Do I need Node.js or a build tool?

No. Serve the folder with any static web server and it works. Node.js is only used by the optional validation scripts.

Which browsers are supported?

The last two versions of Chrome, Edge, Firefox and Safari on desktop and mobile. Newer features degrade gracefully.

Can I use it in a commercial product?

Yes. Everything is MIT licensed, including the templates and the page builder output.

Does it work with React, .NET or Django?

Yes. The markup maps one to one to JSX, Razor and Django templates, and the integration guide covers each stack.
