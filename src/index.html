Ready for AI coding agents

Point Claude Code or any coding agent at this repository. It finds what it needs without guessing:

  • llms.txt and catalog.json list every component, layout and template with file paths
  • CLAUDE.md sets the rules; skills in .claude/skills/ validate, audit and scaffold pages
  • Chat components stream replies from your own model or agent backend
