Appearance

Choose light or dark mode, a brand colour (or any custom colour), density and corner style. Changes apply to every template and are remembered on this device.

Developers: the panel generates CSS for brand.css. See docs/THEMING.md.

Data sources

Charts, tables and the AI assistant read JSON from src/data/. Point them at your own API by entering a base URL. Each endpoint must return the same shape as the sample files.

Relative path or https URL. Requests go to <base>sales.json, <base>orders.json and <base>customers.json. External hosts must be allowed in your Content-Security-Policy connect-src.

sales.jsonObject with monthly, daily, channels, regions, categories, devices and segments arraysOverview, analytics, customers charts
