Features

Everything you need, nothing you don’t

Every template follows W3C standards and MDN best practices, so it drops into any stack.

  • Zero dependencies

    Plain HTML, modular CSS and native ES modules. Nothing to install, nothing to audit.

  • Accessible by default

    Semantic landmarks, keyboard support, visible focus and ARIA only where HTML falls short.

  • Design tokens

    Re-theme everything from one file of CSS custom properties, with built-in dark mode.

  • CSP friendly

    No inline scripts, styles or event handlers. Runs under a strict Content-Security-Policy.

  • Framework agnostic

    Port to ASP.NET Core, React, Next.js, Vue, Django or Laravel with the integration guide.

  • Fast everywhere

    No render-blocking scripts, lazy-loaded media and a tiny footprint for slow networks.

FAQ

Frequently asked questions

Do I need Node.js or a build tool?

No. Serve the src folder with any static web server and it works. Node.js is only used by the optional validation scripts.

Which browsers are supported?

The last two versions of Chrome, Edge, Firefox and Safari, including iOS and Android. Older browsers get a functional, simplified layout.

Can I use the templates in a commercial product?

Yes. Everything is released under the MIT License.

Does it work with React, .NET or Django?

Yes. The markup maps directly to JSX, Razor and Django templates. See the integration guide in the docs folder for step-by-step examples.
