/* ==========================================================================
   Site header & primary navigation
   Mobile: the menu (nav + actions) collapses behind a disclosure button once
   JavaScript has enhanced the page (disclosure.js sets data-state on the
   menu). Without JS the toggle stays hidden and the menu simply wraps below
   the brand, so every link remains reachable. DOM order matches visual
   order at every breakpoint (WCAG 2.4.3).
   ========================================================================== */

.site-header {
  position: sticky;
  inset-block-start: 0;
  z-index: var(--z-sticky);
  border-block-end: var(--border-width) solid var(--color-border);
  background-color: var(--color-bg);
}

.site-header__inner {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: var(--spacing-2xs) var(--spacing-md);
  min-height: var(--header-height);
  padding-block: var(--spacing-2xs);
}

.brand {
  display: inline-flex;
  align-items: center;
  gap: var(--spacing-2xs);
  min-height: var(--target-size);
  margin-inline-end: auto;
  color: var(--color-text);
  font-size: var(--font-size-lg);

Accessibility

Each link group is a <nav> labelled by its heading, so screen reader users can tell the navigation landmarks apart.

Use it in your stack

HTML page

Add the stylesheets to <head> once, then paste the markup anywhere in <body>. Paths assume src/ is your web root.

In <head> 
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/themes.css">
<link rel="stylesheet" href="/assets/css/base.css">
<link rel="stylesheet" href="/assets/css/components/footer.css">
<link rel="stylesheet" href="/assets/css/components/header.css">

React / Next.js

Copy src/assets/ to ui/, convert the markup to JSX (class → className, for → htmlFor) and call init() after render.

JSX 
import '@/ui/css/components/footer.css';
import '@/ui/css/components/header.css';

export function SiteFooter() {
  return <>{/* paste the markup, converted to JSX */}</>;
}

ASP.NET Core

Save the markup as Pages/Shared/Components/_SiteFooter.cshtml (escape a literal @ as @@), render it with <partial name="Components/_SiteFooter" />, and reference the stylesheets in _Layout.cshtml.

Django / Jinja2

Save the markup as templates/components/site-footer.html and use {% include "components/site-footer.html" %}. Load the stylesheets in your base template.
