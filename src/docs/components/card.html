Card

Content card with optional media, stretched link and footer actions. Each card is a size container, so its layout switches to side-by-side when the card itself is wide (container query), wherever it is placed.

card.css

src/assets/css/components/card.css 
/* ==========================================================================
   Card
   Each card is a size container: its internal layout responds to the space
   the card is given (@container), not to the viewport. Browsers without
   container-query support get the stacked (mobile-first) layout.
   ========================================================================== */

.card {
  container: card / inline-size;
  position: relative;
  display: flex;
  flex-direction: column;
  border: var(--border-width) solid var(--color-border);
  border-radius: var(--radius-lg);
  background-color: var(--color-surface-raised);
  box-shadow: var(--shadow-sm);
  overflow: hidden;
}

.card__inner {
  display: grid;
  height: 100%;
}

.card__media {
  width: 100%;
  aspect-ratio: 16 / 10;
  object-fit: cover;
  background-color: var(--color-surface-sunken);
}

.card__body {
  display: flex;
  flex-direction: column;
  gap: var(--spacing-xs);
  padding: var(--spacing-md);
}

.card__title {
  font-size: var(--font-size-lg);
}

.card__title a {
  color: inherit;
  text-decoration: none;
}

/* Stretched link: the whole card is clickable, but only one link is
   announced and tabbable. */
.card__title a::after {
  content: "";
  position: absolute;
  inset: 0;
}

/* Move the focus ring to the whole card where :has() is supported;
   elsewhere the link keeps its own ring. */
@supports selector(:has(*)) {
  .card__title a:focus-visible {
    outline: none;
  }

  .card:has(.card__title a:focus-visible) {
    outline: var(--focus-ring-width) solid var(--color-focus);
    outline-offset: var(--focus-ring-offset);
  }
}

.card__text {
  color: var(--color-text-muted);
}

.card__footer {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: var(--spacing-xs);
  margin-block-start: auto;
  padding-block-start: var(--spacing-xs);
}

/* Interactive controls inside a stretched-link card stay clickable */
.card__footer .btn,
.card__footer a {
  position: relative;
  z-index: var(--z-base);
}

.card__icon {
  display: grid;
  place-items: center;
  width: 2.75rem;
  height: 2.75rem;
  border-radius: var(--radius-md);
  background-color: var(--color-primary-soft);
  color: var(--color-primary);
}

/* Horizontal layout when the card itself is wide enough */
@container card (min-width: 34rem) {
  .card__inner--split {
    grid-template-columns: minmax(12rem, 2fr) 3fr;
  }

  .card__inner--split .card__media {
    height: 100%;
    aspect-ratio: auto;
  }
}

/* ---- Variants ---------------------------------------------------------- */
.card--flat {
  box-shadow: none;
}

.card--highlight {
  border: 2px solid var(--color-primary);
}

/* Stat / KPI card */

/* Product card */

}

Accessibility

The stretched link makes the whole card clickable while only the title link is announced and tabbable. Decorative images use alt="". Controls in the footer stay independently clickable.

Use it in your stack

HTML page

Add the stylesheets to <head> once, then paste the markup anywhere in <body>. Paths assume src/ is your web root.

In <head> 
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/themes.css">
<link rel="stylesheet" href="/assets/css/base.css">
<link rel="stylesheet" href="/assets/css/components/card.css">

React / Next.js

Copy src/assets/ to ui/, convert the markup to JSX (class → className, for → htmlFor) and call init() after render.

JSX 
import '@/ui/css/components/card.css';

export function Card() {
  return <>{/* paste the markup, converted to JSX */}</>;
}

ASP.NET Core

Save the markup as Pages/Shared/Components/_Card.cshtml (escape a literal @ as @@), render it with <partial name="Components/_Card" />, and reference the stylesheets in _Layout.cshtml.

Django / Jinja2

Save the markup as templates/components/card.html and use {% include "components/card.html" %}. Load the stylesheets in your base template.
