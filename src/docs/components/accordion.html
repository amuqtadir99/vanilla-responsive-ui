Accordion

Collapsible sections built on native <details> and <summary>. Siblings that share a name attribute behave exclusively (one open at a time) in supporting browsers.

  • Content
  • HTML + CSS only
  • src/components/accordion.html

HTML

src/components/accordion.html 
<div class="accordion">
  <details class="accordion__item" name="example-faq" open>
    <summary class="accordion__summary">What is included? <svg class="icon" viewBox="0 0 24 24" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg></summary>
    <div class="accordion__panel">
      <p>Templates, components, design tokens, documentation and validation scripts.</p>
    </div>
  </details>
  <details class="accordion__item" name="example-faq">
    <summary class="accordion__summary">Is JavaScript required? <svg class="icon" viewBox="0 0 24 24" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg></summary>
    <div class="accordion__panel">
      <p>No. The accordion works entirely with HTML and CSS.</p>
    </div>
  </details>
</div>

accordion.css

src/assets/css/components/accordion.css 
/* ==========================================================================
   Accordion
   Built on native <details>/<summary>: keyboard, screen reader and no-JS
   support come from the browser. Give sibling <details> the same `name`
   attribute for exclusive (one-open-at-a-time) behaviour where supported.
   ========================================================================== */

.accordion {
  border: var(--border-width) solid var(--color-border);
  border-radius: var(--radius-lg);
  background-color: var(--color-surface-raised);
}

.accordion__item + .accordion__item {
  border-block-start: var(--border-width) solid var(--color-border);
}

.accordion__summary {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: var(--spacing-sm);
  min-height: var(--target-size);
  padding: var(--spacing-sm) var(--spacing-md);
  font-weight: var(--font-weight-semibold);
  cursor: pointer;
  list-style: none;
}

.accordion__summary::-webkit-details-marker {
  display: none;
}

.accordion__summary:hover {
  background-color: var(--color-surface);
}

.accordion__summary:focus-visible {
  outline-offset: calc(var(--focus-ring-width) * -1);
}

.accordion__item:first-child .accordion__summary {
  border-start-start-radius: var(--radius-lg);
  border-start-end-radius: var(--radius-lg);
}

.accordion__item:last-child:not([open]) .accordion__summary {
  border-end-start-radius: var(--radius-lg);
  border-end-end-radius: var(--radius-lg);
}

.accordion__summary .icon {
  transition: transform var(--duration-base) var(--ease-standard);
}

.accordion__item[open] > .accordion__summary .icon {
  transform: rotate(180deg);
}

.accordion__panel {
  padding: 0 var(--spacing-md) var(--spacing-md);
  color: var(--color-text-muted);
}

Accessibility

Native elements provide keyboard support (Enter/Space), expanded state and no-JS behaviour for free. Do not put interactive elements inside <summary>.

Use it in your stack

HTML page

Add the stylesheets to <head> once, then paste the markup anywhere in <body>. Paths assume src/ is your web root.

In <head> 
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/themes.css">
<link rel="stylesheet" href="/assets/css/base.css">
<link rel="stylesheet" href="/assets/css/components/accordion.css">

React / Next.js

Copy src/assets/ to ui/, convert the markup to JSX (class → className, for → htmlFor) and call init() after render.

JSX 
import '@/ui/css/components/accordion.css';

export function Accordion() {
  return <>{/* paste the markup, converted to JSX */}</>;
}

ASP.NET Core

Save the markup as Pages/Shared/Components/_Accordion.cshtml (escape a literal @ as @@), render it with <partial name="Components/_Accordion" />, and reference the stylesheets in _Layout.cshtml.

Django / Jinja2

Save the markup as templates/components/accordion.html and use {% include "components/accordion.html" %}. Load the stylesheets in your base template.
