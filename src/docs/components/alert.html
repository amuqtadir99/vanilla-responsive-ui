Accessibility

Status is never conveyed by colour alone: each alert has an icon and a text title. For messages inserted dynamically, put them inside a live region (role="status" for polite, role="alert" for urgent). Badges that carry meaning include full text for screen readers.

Use it in your stack

HTML page

Add the stylesheets to <head> once, then paste the markup anywhere in <body>. Paths assume src/ is your web root.

In <head> 
<link rel="stylesheet" href="/assets/css/tokens.css">
<link rel="stylesheet" href="/assets/css/themes.css">
<link rel="stylesheet" href="/assets/css/base.css">
<link rel="stylesheet" href="/assets/css/components/feedback.css">

React / Next.js

Copy src/assets/ to ui/, convert the markup to JSX (class → className, for → htmlFor) and call init() after render.

JSX 
import '@/ui/css/components/feedback.css';

export function Alert() {
  return <>{/* paste the markup, converted to JSX */}</>;
}

ASP.NET Core

Save the markup as Pages/Shared/Components/_Alert.cshtml (escape a literal @ as @@), render it with <partial name="Components/_Alert" />, and reference the stylesheets in _Layout.cshtml.

Django / Jinja2

Save the markup as templates/components/alert.html and use {% include "components/alert.html" %}. Load the stylesheets in your base template.
