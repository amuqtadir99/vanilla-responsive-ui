Foundations

Colours

Every colour is a CSS custom property in src/assets/css/tokens.css, with light and dark values. Swatches below are live: switch the theme or a brand preset and they update. Contrast for each pair is verified by the test suite.

Brand presets

Set data-brand on <html>, or pick any colour in the theme panel.

  • data-brand="indigo"
  • data-brand="teal"
  • data-brand="violet"
  • data-brand="rose"
  • data-brand="amber"
  • data-brand="slate"
Preset attributes 
<html lang="en" data-brand="teal" data-density="compact" data-radius="round">
