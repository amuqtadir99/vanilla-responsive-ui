Spacing and shape

Spacing uses a 4px base in rem, so it grows with the user’s font size. Radii and shadows complete the shape language; density and corner presets change them globally.

Spacing

  • --spacing-3xs0.25rem
  • --spacing-2xs0.5rem
  • --spacing-xs0.75rem
  • --spacing-sm1rem
  • --spacing-md1.5rem
  • --spacing-lg2rem
  • --spacing-xl3rem
  • --spacing-2xl4rem
  • --spacing-3xl6rem
