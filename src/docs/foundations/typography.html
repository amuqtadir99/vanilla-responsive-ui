Typography

System font stacks (no web fonts) and a fluid type scale built with clamp() using rem + vw, so text scales with the viewport and still zooms to 200%.

Type scale

  • --font-size-xs 0.75remAccessible by default
  • --font-size-sm 0.875remAccessible by default
  • --font-size-base clamp(1rem, 0.96rem + 0.2vw, 1.0625rem)Accessible by default
  • --font-size-lg clamp(1.125rem, 1.06rem + 0.32vw, 1.25rem)Accessible by default
  • --font-size-xl clamp(1.25rem, 1.12rem + 0.65vw, 1.5rem)Accessible by default
  • --font-size-2xl clamp(1.5rem, 1.25rem + 1.25vw, 2rem)Accessible by default
  • --font-size-3xl clamp(1.875rem, 1.45rem + 2.1vw, 2.75rem)Accessible by default
  • --font-size-4xl clamp(2.25rem, 1.6rem + 3.25vw, 3.75rem)Accessible by default
  • --font-size-5xl clamp(2.5rem, 1.6rem + 4.5vw, 4.75rem)Accessible by default
