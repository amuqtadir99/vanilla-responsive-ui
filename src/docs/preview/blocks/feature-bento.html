Features

Everything you need to ship, nothing you don’t

Every block follows W3C standards and MDN best practices, so it drops into any stack.

  • Design tokens drive everything

    Change one brand colour and every button, chart and focus ring follows, with contrast checked in light and dark mode.

  • Accessible by default

    Keyboard support, visible focus and screen-reader text are built in, not bolted on.

    Lighthouse accessibility: 98
    Keyboard coverage: 90%
    Contrast pairs passing: 100%

  • Zero dependencies

    Nothing to install, nothing to audit. Pages load in milliseconds.

  • Strict CSP

    No inline scripts, styles or handlers. XSS-safe rendering everywhere.

  • Copy, paste, ship

    Every block is one section of semantic HTML.

    <section class="hero">
      <h1>Hello</h1>
    </section>

  • Works in any framework

    Guides for each stack, and the markup ports one to one.

    • React
    • Next.js
    • Vue
    • Svelte
    • ASP.NET
    • Django
    • Laravel
    • Rails
